The purpose is not to make every product sound healthier. It is to keep five different states separate:

1. code merged to the connected remote;
2. a release artifact built or uploaded;
3. Apple accepting or registering a build;
4. a tester actually receiving the product;
5. a user returning evidence that changes the roadmap.

- A real user changes a testing stage even when the program is informal.
